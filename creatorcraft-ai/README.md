# CreatorCraft AI

CreatorCraft AI is a premium creative studio platform for music, video, brand strategy, websites, and AI-powered marketing workflows.

## Stack

- Next.js App Router
- TypeScript
- React 19
- Supabase Auth and Postgres
- Stripe Billing
- OpenAI API
- Resend email

## Local run

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
npm run start
```

## Required environment variables

Copy `.env.example` to `.env.local` and fill in the values for your environment.
