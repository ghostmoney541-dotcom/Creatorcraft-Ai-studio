# CreatorCraft AI

This repository is being prepared as a production-ready Next.js application for the CreatorCraft AI platform.

The active application root is `creatorcraft-ai/`.

## Project structure

- `creatorcraft-ai/` — Next.js App Router project
- `README.md` — repository-level overview

## Current repair status

- Cleaned and standardized the Next.js app directory configuration
- Fixed malformed JSX and invalid app shell structure
- Established the foundation for the marketing site, auth flow, dashboard, and platform modules
- Prepared environment and deployment configuration for Supabase, OpenAI, Stripe, and email services

## Local development

```bash
cd creatorcraft-ai
npm install
npm run dev
```

## Production build

```bash
cd creatorcraft-ai
npm run build
npm run start
```
